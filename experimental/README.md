# Experimental

This is a directory where anything goes (*) - a place for experiments and tools
which are not code reviewed and/or do not meet the quality standards of the
rest of the codebase. (But the author should at least read through the code.)

(*) Caveat: this will be published in GitHub along with the rest of Fuzzilli,
so keep that in mind.

Create a subdirectory for your project and commit there.
